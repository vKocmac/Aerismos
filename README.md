# Aerismos — «να ανοίξω τα παράθυρα;»

Μία σελίδα που απαντά, τώρα, αν συμφέρει να ανοίξεις τα παράθυρα.

**Live:** https://vkocmac.github.io/Aerismos/

Η σχετική υγρασία από μόνη της δεν απαντά τίποτα. Η σύγκριση γίνεται σε
**περιεκτικότητα υγρασίας w (g/kg ξηρού αέρα)** — αυτό είναι όλο το νόημα.
Ένας αέρας 30 °C / 40% RH κουβαλάει περισσότερο νερό από έναν 20 °C / 70% RH,
παρότι η δεύτερη ένδειξη τρομάζει περισσότερο.

## Τι δείχνει

- **Ετυμηγορία** — ΑΝΟΙΞΕ ΔΙΑΠΛΑΤΑ / ΑΝΟΙΞΕ / ΟΡΙΑΚΟ / ΚΛΕΙΣΤΑ / ΜΗΝ ΑΝΟΙΓΕΙΣ — ΖΕΣΤΗ
- **Κέρδος ή κόστος** σε g/kg, K και kJ/kg, και **έως πόσα λίτρα νερού** βγάζεις
  σε πλήρη εναλλαγή αέρα
- **Ψυχρομετρικό γράφημα** με τη ζώνη άνεσης ASHRAE 55 της τρέχουσας εποχής, το
  όριο των 12 g/kg, και δύο κουκκίδες: πού είσαι τώρα, πού καταλήγεις αν ανοίξεις
- **Έλεγχο με πραγματική μέτρηση** — METAR από το Ελ. Βενιζέλος (LGAV), για να
  ξέρεις αν το μοντέλο λέει κάτι άσχετο
- **Τις επόμενες τρεις ώρες**, για το «να περιμένω μισή ώρα;»

## Χρήση

Οι τιμές του εσωτερικού χώρου μπαίνουν στη διεύθυνση, όχι σε localStorage — ώστε
ο καθένας να βάζει bookmark τη δική του:

```
https://vkocmac.github.io/Aerismos/?loc=spiti&t=26&rh=55
```

| παράμετρος | τιμές |
|---|---|
| `loc` | `spiti` (Αργυρούπολη) · `schinias` · `agdim` (Άγ. Δημήτριος) |
| `t` | θερμοκρασία μέσα, °C |
| `rh` | σχετική υγρασία μέσα, % |
| `season` | προαιρετικό: `winter` / `summer` — παρακάμπτει την αυτόματη επιλογή |

## Πηγές δεδομένων

- **[Open-Meteo](https://open-meteo.com/)** — καιρός, χωρίς κλειδί, άδεια
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Το `w` έξω υπολογίζεται
  **πάντα από το σημείο δρόσου**, ποτέ μέσω της RH: το μοντέλο σφάλλει 5-10 μονάδες
  στη RH αλλά μόνο ~1-1,5 K στο σημείο δρόσου.
- **METAR LGAV** — NOAA/NWS Aviation Weather Center. Πραγματική μέτρηση ανά 30΄.
  Συγκρίνεται με το μοντέλο **στις συντεταγμένες του αεροδρομίου**, όχι του σπιτιού:
  η διαφορά σπιτιού–αεροδρομίου είναι πραγματική χωρική διαφορά, όχι σφάλμα.

## Άνεση

Η ζώνη άνεσης υπολογίζεται από **PMV κατά ISO 7730** (επαληθευμένο σε τιμές
αναφοράς του προτύπου, εντός ±0,01), όχι από ζωγραφισμένο πολύγωνο. Χειμώνας
1,0 clo (Νοέ–Απρ), καλοκαίρι 0,5 clo (Μάι–Οκτ).

Δύο σταθερές είναι **δικές μας παραδοχές**, όχι πρότυπο, και σημειώνονται ως τέτοιες
στον κώδικα: η ανοχή 1,5 K για το ρεύμα των ανοιχτών παραθύρων (το ASHRAE 55 πάνω
από 0,20 m/s απαιτεί τη μέθοδο SET, όχι σταθερή προσαύξηση) και το περιθώριο
PMV 0,30 πριν βγει βέτο ζέστης. Όλα τα κατώφλια είναι μαζεμένα στην κορυφή του
`<script>`.

## Το cron του METAR σταματά κάθε 60 ημέρες

Το `aviationweather.gov` δεν στέλνει CORS headers, οπότε η σελίδα δεν μπορεί να το
καλέσει από τον browser. Ένα GitHub Action ανά 15΄ το τραβάει και γράφει το
`metar.json` στο repo.

**Το GitHub απενεργοποιεί τα scheduled workflows μετά από 60 ημέρες χωρίς push από
άνθρωπο** — τα commits του bot δεν μετράνε. Θα έρθει σχετικό email. Τότε:

```bash
gh workflow enable metar.yml --repo vKocmac/Aerismos
```

ή Actions tab → *Enable workflow*, ή απλώς ένα `deploy.ps1`.

Αν δεν το προσέξεις δεν χαλάει τίποτα: η σελίδα βλέπει ότι το `metar.json` είναι
παλιότερο από 2 ώρες, γράφει «Έλεγχος LGAV: μη διαθέσιμος» και συνεχίζει με μία πηγή.

## Ανάπτυξη

Ένα αρχείο, μηδέν dependencies. Πηγή αλήθειας: `06 Tools/Aerismos/` στο vault.
Τοπικά: `python -m http.server 8778` μέσα στον φάκελο (χρειάζεται server, όχι
`file://`, γιατί το `metar.json` φορτώνεται με fetch). Ανέβασμα: `deploy.ps1`.
